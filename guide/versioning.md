# 版本与功能范围

## 稳定版

当前手册以 `2.1.12` 为稳定基线。这个版本重点包含：

- 更紧凑的无损监控数据存储和真正的分层接力。
- 大数据库查询、后台维护和低性能主控适配。
- 仪表盘、服务器状态、计费流量、流量校准和数据库文件组成。
- 内置 HTTPS、Cloudflare Tunnel、远程终端和文件管理改进。
- 完整备份、仅导出配置以及跨上游和本分支的导入兼容。
- 日报、周报、月报、流量告警、主题和公共接口统一使用生效流量口径。
- 上游 `1.3.1`、`1.3.2` 与本分支旧版本的迁移页面。
- 后台导航、页面标题、手机端布局和远程终端体验改进。

具体构建标识以“关于”页面和 Release 中的七位构建码为准。同一个版本号可能有同版本更新，排查问题时只提供 `2.1.12` 不够，还应同时提供七位构建码。

## 快照版

本轮 Snapshot 验证的功能已经全部纳入 `2.1.12`。后续 Snapshot 仍用于公开测试尚未转正的新功能，具体差异会在对应 Release 和文档页面中明确标注。

::: warning 不要把 Snapshot 当成自动升级通道
生产环境升级前应阅读对应 Release，备份完整 `data` 目录，并确认快照是否包含数据库迁移。快照文档会明确标注与稳定版的差异。
:::

## 与上游的关系

本分支基于 [komari-monitor/komari](https://github.com/komari-monitor/komari) 持续开发，但数据库结构、后台界面、Agent 更新源和部分公共接口兼容逻辑已经不同。

本手册统一使用以下口径：

- “与上游一致”表示当前 Lite 已按实际实现核对，所述行为可直接按同一方式使用。
- “上游兼容”只表示文中明确列出的版本、数据或接口可以迁移或调用，不代表镜像、数据库和后台实现完全相同。
- “官方 Agent”表示上游官方 Agent 的行为；当前 `nuomiiiii/komari-agent` 与其协议和默认行为一致，并已与 Lite 服务端核对。
- “本项目官方脚本”表示 `nuomiiiii/komari` 仓库发布的安装脚本，不是上游仓库的脚本。
- Lite 与上游确有差异时，页面会直接标注差异和适用版本，不要求读者自行判断。

- 不要混用两个项目的 Docker 镜像地址。
- 从上游切换到本分支前必须备份。
- 本分支会尽量兼容上游数据迁移；是否支持应以目标版本 Release 为准。
- 第三方主题应使用公共接口，不应直接依赖内部数据库结构。
