# 版本与功能范围

## 稳定版

当前手册以 Lite `2.3.0`、Lite-agent `2.3.0.0` 和 Lite-Theme `1.0.1` 为稳定基线。除延续 2.2.x 的仪表盘、主题解耦、监测和流量能力外，2.3.0 重点包含：

- 可视化仪表盘配置、预制布局、模块排序、卡片宽度和 Top 5/10/15/20 排行。
- 近 15 分钟丢包、平均时延、延迟抖动、资源和计费流量等排行模块。
- 实时概览与历史图表独立刷新周期、短时结果缓存和返回页面后的无闪烁恢复。
- 系统 Web UI 与公共大屏主题解耦；主题只影响公开页面，并至少保留一个可用主题。
- 当前主题声明的服务器详情、网络总览和 Ping 任务跳转能力，以及旧主题安全回退。
- 离线通知、延迟监测告警和流量定时报告的新服务器默认配置。
- 负载通知的“默认开启”、当前告警视图和按服务器静默。
- 新增服务器自动排序开关；开启后只整理新节点，不改动已有服务器顺序。
- 配合 Lite-agent `2.3.0.0` 使用心跳、读超时和快速重连，降低进程运行但面板误判离线的概率。
- 回程任务多选创建、批量修改，以及 CUG VIP / CUG 优化 / CUG 待确认判定。
- 主题配置中的节点选择器、Ping 任务选择器，以及清单多语言名称、作者和描述。
- 上游 `1.3.1` 与 `1.4.x` 指标数据库的 V4 迁移，以及 Linux 直装失败回滚。
- 产品、程序、镜像、安装目录和服务正式统一为 Lite 命名，同时保留旧部署的端口与数据兼容。
- 以 MUI 为主的管理后台、独立服务器详情页和五步首次安装引导。
- 账单中心：服务器资费、日月年汇总、附加费用、剩余价值、到期提醒、多币种参考换算和账目冲销。
- 新安装默认使用 Lite-Theme，主题清单优先读取 `Lite-theme.json`，继续兼容旧 `komari-theme.json`。
- Lite-agent 独立发版并迁移到 Lite 安装目录；WebSocket 增加心跳、读超时和快速重连。

具体构建标识以“关于”页面和 Release 中的七位构建码为准。同一个版本号可能有同版本更新，排查问题时除 `2.3.0` 外还应同时提供七位构建码。

## 快照版

`2.3.0` 之后的 Snapshot 用于公开测试尚未转正的新功能，具体差异以对应 Release 为准。当前快照中的“新服务器按地区自动排序”等能力不作为 2.3.0 正式版默认功能写入稳定口径。

::: warning 不要把 Snapshot 当成自动升级通道
生产环境升级前应阅读对应 Release，备份完整 `data` 目录，并确认快照是否包含数据库迁移。快照文档会明确标注与稳定版的差异。
:::

## 与上游的关系

本分支基于 [komari-monitor/komari](https://github.com/komari-monitor/komari) 持续开发，但数据库结构、后台界面、Agent 更新源和部分公共接口兼容逻辑已经不同。

本手册统一使用以下口径：

- “与上游一致”表示当前 Lite 已按实际实现核对，所述行为可直接按同一方式使用。
- “上游兼容”只表示文中明确列出的版本、数据或接口可以迁移或调用，不代表镜像、数据库和后台实现完全相同。
- “Lite-agent”表示 `nuomiiiii/Lite-agent` 独立仓库的配套 Agent；协议中的旧字段或请求头仅为兼容，不代表仍使用旧 Agent 发布源。
- “本项目官方脚本”表示 `nuomiiiii/lite` 仓库发布的安装脚本，不是上游仓库的脚本。
- Lite 与上游确有差异时，页面会直接标注差异和适用版本，不要求读者自行判断。

- 不要混用两个项目的 Docker 镜像地址。
- 从上游切换到本分支前必须备份。
- 本分支会尽量兼容上游数据迁移；当前已适配上游 `1.3.1`、`1.3.2` 和 `1.4.x` 指标布局，是否支持其他版本应以目标版本 Release 为准。
- 第三方主题应使用公共接口，不应直接依赖内部数据库结构。
