# 版本与功能范围

## 稳定版

当前手册以 `2.1.12` 为稳定基线。这个版本重点包含：

- 更紧凑的无损监控数据存储和真正的分层接力。
- 大数据库查询、后台维护和低性能主控适配。
- 仪表盘、服务器状态、计费流量和数据库文件组成。
- 上游 `1.3.1`、`1.3.2` 与本分支旧版本的迁移页面。
- 后台导航、页面标题、手机端布局和远程终端体验改进。

具体构建标识以“关于”页面和 Release 中的七位构建码为准。同一个版本号可能有同版本更新，排查问题时只提供 `2.1.12` 不够，还应同时提供七位构建码。

## 快照版

Snapshot 用于公开测试尚未转正的功能，可能包含内置 HTTPS、备份导入导出增强、服务器流量额度扩展等内容。

::: warning 不要把 Snapshot 当成自动升级通道
生产环境升级前应阅读对应 Release，备份完整 `data` 目录，并确认快照是否包含数据库迁移。快照文档会明确标注与稳定版的差异。
:::

## 与上游的关系

本分支基于 [komari-monitor/komari](https://github.com/komari-monitor/komari) 持续开发，但数据库结构、后台界面、Agent 更新源和部分公共接口兼容逻辑已经不同。

- 不要混用两个项目的 Docker 镜像地址。
- 从上游切换到本分支前必须备份。
- 本分支会尽量兼容上游数据迁移；是否支持应以目标版本 Release 为准。
- 第三方主题应使用公共接口，不应直接依赖内部数据库结构。
