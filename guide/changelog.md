# 版本更新

当前稳定基线是 `2.2.3`。同一个版本号可能有同版本更新，排查问题时请同时提供“关于”页面或 Release 中的七位构建码。

尚未转正的 Snapshot 功能不会写入本页。完整构建产物和安装命令以对应 [GitHub Release](https://github.com/nuomiiiii/komari/releases) 为准。

## 2.2.3

- 正式版：2026-08-13
- 同版本第一次更新：2026-08-17，构建码 `sy75112`

### 通知

- 离线通知、延迟监测告警和流量定时报告增加“新服务器默认配置”。只作用于之后新加入的服务器，不会改写已有服务器的规则。
- 负载通知增加“当前告警”视图，可按规则和服务器搜索正在触发的告警。
- 可对单台服务器设置 24 小时、3 天、7 天或永久静默，也可随时解除。静默只暂停通知渠道消息，不停止告警检测，也不影响当前告警、仪表盘、实时负载和监控图表。

### 主题与后台

- 主题配置新增节点选择器和 Ping 任务选择器。
- 主题清单的名称、作者和描述支持多语言对象，缺少对应语言时回退到可用文本。
- 后台继续兼容主题声明的内置表单、自定义配置页和站内跳转三种配置方式。
- 上传主题后预览图可正常显示；大文件主题包、备份恢复和首次安装恢复改为分段传输，网络中断后只需重试失败部分。
- PWA 清单实时使用后台站点名称、描述和 `/favicon.ico`，并以 `no-store` 避免改名后继续使用旧缓存。第三方主题缺少 manifest 时会生成合理默认内容。
- 后台顶栏和侧栏在页面代码加载期间保持显示；节点列表、节点详情和延迟任务的数据会在后台页面间复用。

### 回程与升级

- 补充 `210.78.0.0/19` 的联通 9929 回程覆盖，完善 CUG VIP 路径判定。
- 上游 `1.4.x` 的 `metric_label_sets` 指标布局可进入与 `1.3.1` 相同的 V4 迁移流程。同时检测到两套完整上游布局时会拒绝迁移。
- Linux 直装在线更新在启用内置 HTTPS 后不再因本机证书名称校验误判失败；安装或升级失败会回滚，避免留下不完整安装状态。

## 2.2.2

- 正式版：2026-08-09
- 同版本第一次更新：2026-08-12，构建码 `78518cc`

### 监测与通知

- 负载通知增加“默认开启”。新加入的服务器可自动纳入已开启该选项的规则，现有服务器不受影响。
- 编辑延迟监测任务并移除服务器时，会同步删除该服务器在该任务下的延迟告警。
- 升级或重启后会清理“服务器和任务仍存在、但服务器已不再属于该任务”的遗留延迟告警。
- 公开大屏的旧版延迟记录接口、新版指标曲线与统计接口统一按当前任务关联过滤；取消关联后不再继续显示该任务历史延迟。重新关联后仍可查看保留的历史数据。
- 部分主题请求任务清单时没有携带服务器 UUID，需要主题自行按节点过滤。

### 回程线路

- 新增回程任务时，探测节点可在同一选择框内多选，一次创建多台服务器的同配置任务。
- 任务列表支持选择、全选和批量修改目标、周期、运营商、地区及 IP 地址。
- 联通回程同时出现 AS10099 与 AS9929 时判定为 CUG VIP，同时出现 AS10099 与 AS4837 时判定为 CUG 优化。仅能确认 AS10099、无法确认中间承载网时显示为 CUG 待确认。

### 后台体验

- 系统通用设置新增“减少动态效果”，默认关闭。开启后页面、页签和侧栏改为即时切换，不改变实时概览和历史图表的刷新间隔。
- 电脑端只保留主内容区滚动；手机端打开左侧导航时不再下拉出大面积空白。
- `komari-web` 只保留后台、安装、升级、恢复、终端和管理界面；公开大屏继续由当前启用主题提供。

## 2.2.1

- 正式版：2026-08-07
- 同版本第一次更新：2026-08-08，构建码 `07e8284`

- 系统 Web UI 与公共大屏主题解耦，主题只影响公开页面，并至少保留一个可用主题。
- 默认提供 Nezha 主题；原经典主题改为独立的 [komari-Classic](https://github.com/nuomiiiii/komari-Classic)。
- 新增近 15 分钟丢包排行，并调整平均时延、延迟抖动排行和仪表盘跳转。
- 实时概览与历史图表独立刷新，默认均为 30 秒；旧的 300 秒历史刷新按 120 秒处理。
- 从公开大屏返回后台时，仪表盘先恢复上一帧再静默更新。
- 新增“CN2 待确认”状态：证据不足以区分 GIA 和 GT 时保留上一次已确认线路，不累计切线次数，也不触发告警。
- 新节点首次设置流量统计方式时默认选择“总和”；已有节点配置保持不变。
