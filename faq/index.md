# 常见问题

## 页面能打开，终端为什么 403？

普通页面和终端不是同一连接。终端需要 WebSocket、有效登录会话、2FA 和在线 Agent。检查反向代理的 Upgrade 头、Origin、Cloudflare Access 和浏览器访问域名。

## 为什么换证书后 Agent 403？

证书不会修改 Agent Token。更常见的是 Agent endpoint 改到了另一端口或实例、旧 Token 已轮换，或代理把请求送到错误后端。

## 数据库一小时增加很多，是否代表一天线性增长？

不一定。新部署的原始层、分钟层和五分钟层会依次填充，早期增长不能直接乘以 24 或保留天数。稳定占用还取决于服务器上报间隔、探测间隔、任务数和数据波动。

## 为什么回收空间前后变化不大？

数据库可能仍有有效数据、WAL 或迁移临时页；空闲页也可能已被后续写入复用。先看主库、监控库、WAL 和 SHM 的总占用，再判断是否异常。

## 为什么 WAL 不变但主数据库变大？

检查点会把 WAL 页写回主文件。WAL 维持在一个工作大小、主文件增长是正常过程，应观察总占用和保留周期是否趋于稳定。

## 为什么关闭内置 HTTPS 后 HTTP 仍无法访问？

确认 HTTP 端口仍被容器映射并被防火墙允许。浏览器可能记住 HSTS，端口也可能仍写成 HTTPS 端口。直接检查 `http://主机:25774` 和后端启动日志。

## 为什么容器映射了 HTTPS 端口仍访问不了？

后台启用端口、容器内部监听端口和宿主机发布端口必须一致。`127.0.0.1:端口:端口` 只允许宿主机本地访问；VPN 客户端直连应绑定 VPN 地址或所有地址并配合防火墙。

## 旗帜没有显示为对应地区

输入 ISO 3166-1 两位代码，例如 `HK`、`US`、`JP`。主题需要支持该代码的旗帜映射；缺少 emoji 字体时应使用图标资源而不是依赖系统字符。

## 如何提交有效问题？

请同时提供：

- 版本号和七位构建码。
- Docker、脚本或二进制部署方式。
- CPU 架构、内存和数据库大小。
- 相关时间段的日志。
- 可复现步骤与浏览器控制台错误。

提交到 [nuomiiiii/komari Issues](https://github.com/nuomiiiii/komari/issues)。公开内容前先删除域名、IP、Token、Tunnel 凭据和备份文件。
