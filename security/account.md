# 账号、通行密钥与登录会话

账号安全设置位于“账户与安全”。公网使用的 Lite 建议启用两步验证，并为管理员账号使用独立密码。

## 密码与登录保护

Lite 使用 Argon2id 保存新密码。新设置的密码至少需要 8 个字符，并同时包含大写字母、小写字母和数字。由旧版本升级的账号不需要手工重置密码；下一次密码登录成功后，旧密码摘要会自动升级。

连续输入错误密码或验证码会触发短时限制。页面提示请求过于频繁时，请等待一段时间后再试，不要持续刷新或重复提交。

修改管理员密码会退出本站全部登录会话，包括当前会话，并使相关远程授权失效。保存后需要使用新密码重新登录。

## 头像

点击“账户与安全”中的头像可以上传、裁剪和缩放新头像，也可以恢复为用户名首字母头像。支持 JPG、PNG 和 WebP；原图不能超过 5 MB 或 1600 万像素，不支持 GIF、SVG 和 HEIC。

## 通行密钥

登录页支持使用通行密钥登录。在“账户与安全 → 登录方式 → 通行密钥”中，可以添加、重命名或删除通行密钥，并选择保存到 Windows Hello 或 Bitwarden 等密码管理器。选择“密码管理器”后，由浏览器和系统弹窗列出当前设备可用的管理器；实际是否出现某个管理器取决于其浏览器扩展、系统权限和通行密钥功能是否已经启用。

添加新通行密钥前，需要使用当前密码确认身份；已启用 2FA 时还需输入验证码。已有通行密钥时也可直接用它确认，只有 SSO 登录方式的账号可以通过已绑定的 SSO 账号确认。为避免账号无法登录，Lite 不允许删除最后一种可用登录方式。

通行密钥绑定注册时使用的域名。正式站点应通过 HTTPS 域名访问；在本机通过 IP 地址访问时，请改用 `localhost`。更换域名后，原通行密钥可能无法使用，因此应保留密码或 SSO 等备用登录方式，并在新域名下重新添加通行密钥。

## 启用两步验证

1. 在“账户与安全”中开始设置 2FA。
2. 使用验证器扫描二维码或保存 Secret。
3. 输入验证器当前显示的验证码完成启用。
4. 退出并重新登录一次，确认密码和验证码均可正常使用。

2FA Secret 会在 Lite 数据库中加密保存。同一个 TOTP 验证码只能成功使用一次；刚完成登录或敏感操作后再次验证时，如果验证器仍显示原来的数字，请等待下一组验证码。

完整备份会包含恢复 2FA 所需的实例密钥。任何拿到完整备份的人都可能恢复其中的账号和 2FA 数据，因此必须按[备份、导入与迁移](/data/backup)中的要求保护备份文件。

## 敏感操作

切换到“部署指令”或重置节点 Token 时，已启用 2FA 的账号需要按提示输入当前验证码。

修改管理员用户名或密码，以及管理头像、通行密钥、2FA 和 SSO 绑定，均要求管理员登录会话，不能用 API Key 代替。API Key 也不能下载或上传备份、进入主题管理、切换主题，以及查看或重置节点 Token。外部脚本的完整限制见 [API Key 权限限制](/development/api#api-key-权限限制)。

远程终端、文件管理和远程执行需要单独重新验证：可以使用通行密钥，已启用 2FA 时输入当前 TOTP，未启用 2FA 时输入管理员密码。生成的短期授权绑定当前管理员登录会话，最长 10 分钟；终端与文件管理共用 `remote` 范围，远程执行使用独立的 `exec` 范围。短期授权到期后需重新验证才能创建新连接或提交执行，已连接终端仍按连接时限与登录状态保持。API Key 不能签发或使用远程授权，详见[远程终端与文件](/remote/terminal#重新验证)。

MCP 代理使用单独的客户端授权流程。管理员需要在 Lite 中选择节点，再使用通行密钥、已启用的 2FA 验证码或管理员密码重新验证。临时授权默认为 30 分钟，站点最长时长默认为 24 小时，可调高到 72 小时；也可在授权表单勾选“长期授权”，使其在撤销前一直有效。API Key 不能代替 MCP 授权，详见[MCP 代理与 AI 授权](/remote/mcp)。

仅使用 SSO 的账号可通过已绑定的通行密钥或已启用的 2FA 完成远程管理和 MCP 验证。账号没有密码、2FA 和通行密钥时，暂时不能完成远程重新验证。

## 会话管理

“账户与安全 → 登录会话”会显示每个会话的登录方式、创建时间、剩余时间以及最近活动的浏览器和 IP。可以删除单个会话，也可以退出其他全部会话。

全局自动登出时长默认为 24 小时，可设置为 1 分钟至 30 天。点击、键盘、触摸、滚动、页面重新显示及普通页面操作会重新开始倒计时，后台自动刷新不会续期。修改全局时长后，现有会话的最长到期时间也会受到新设置限制。

退出登录、登录会话到期或在后台删除该会话后，其关联的浏览器远程连接、短期授权和临时 MCP 授权会失效。长期 MCP 授权不绑定浏览器会话，退出登录和 Lite 正常重启后仍保留；修改密码、相关账号安全变更、授权人账号删除或手动撤销时仍会失效。

怀疑账号、会话或备份泄露时，应立即修改管理员密码，并检查 Agent 与第三方服务凭据是否需要更换。
