# 账号、2FA 与登录会话

账号安全设置位于“账户与安全”。公网使用的 Lite 建议启用两步验证，并为管理员账号使用独立密码。

## 密码与登录保护

Lite `2.3.2` 使用 Argon2id 保存新密码。由旧版本升级的账号不需要手工重置密码；下一次密码登录成功后，旧密码摘要会自动升级。

连续输入错误密码或验证码会触发短时限制。页面提示请求过于频繁时，请等待一段时间后再试，不要持续刷新或重复提交。

修改管理员密码会让现有登录会话和远程授权失效，需要使用新密码重新登录。

## 启用两步验证

1. 在“账户与安全”中开始设置 2FA。
2. 使用验证器扫描二维码或保存 Secret。
3. 输入验证器当前显示的验证码完成启用。
4. 退出并重新登录一次，确认密码和验证码均可正常使用。

2FA Secret 会在 Lite 数据库中加密保存。同一个 TOTP 验证码只能成功使用一次；刚完成登录或敏感操作后再次验证时，如果验证器仍显示原来的数字，请等待下一组验证码。

完整备份会包含恢复 2FA 所需的实例密钥。任何拿到完整备份的人都可能恢复其中的账号和 2FA 数据，因此必须按[备份、导入与迁移](/data/backup)中的要求保护备份文件。

## 敏感操作

切换到“部署指令”并读取 Agent Token 时，已启用 2FA 的账号需要输入当前验证码。

远程终端、文件管理和远程执行使用单独的页面重新验证：已启用 2FA 时输入当前 TOTP，未启用时重新输入管理员密码。普通登录状态、API Key 或其他页面已经完成的验证不能代替这一步，详见[远程终端与文件](/remote/terminal#重新验证)。

仅使用 SSO、未启用 2FA 且没有本地密码的账号暂时不能使用远程管理。已启用 2FA 的 SSO 账号可以通过当前 TOTP 验证码完成远程重新验证。

## 会话管理

退出登录或在后台删除某个登录会话后，该会话关联的远程连接和短期授权也会失效。修改密码或账号安全状态时，受影响的远程连接同样会被关闭。

怀疑账号、会话或备份泄露时，应立即修改管理员密码，并检查 Agent 与第三方服务凭据是否需要更换。
