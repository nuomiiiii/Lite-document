# 流量与报告

流量页面、主题、仪表盘、报告和告警应使用一致的服务器设置，但它们展示的时间范围不同。

## 实际流量与额度

- **实际流量**：Agent 已经采集到的上传和下载。
- **基础额度**：服务器通常计费周期内的流量上限。
- **重置流量额度**：本周期因服务商重置、补偿等原因追加的额度。
- **本周期有效额度**：基础额度与本周期重置额度之和。

> **本周期有效额度** = 基础流量限额 + 本周期重置流量额度

重置流量额度不会修改 Agent 已经发生的流量，也不会伪造历史记录。进入下一个计费周期后，本周期追加额度自动清零。

## 统计方式

统计方式由服务器的流量设置统一决定。重置额度沿用同一个统计方式，不再维护第二套上传、下载或合计规则。

修改统计方式后，主题、进度条和流量告警会按新口径计算，但过去已经发出的报告不会被自动改写。

## 日报、周报和月报

报告从精确流量账本按北京时间日期汇总：

- 日报：指定自然日。
- 周报：对应自然周范围。
- 月报：对应自然月范围。

“立即发送今日报告”还包含今天尚未结束的实时数据。由于后台写入和报告触发存在时间差，临界秒可能与页面刷新时看到的数字有极小时间差。

## 计费流量

只有设置了价格的服务器进入计费流量汇总。服务器没有价格或明确为免费时：

- 节点流量仍正常保存。
- 服务器详情仍显示上传和下载。
- 不进入仪表盘计费汇总。
- 不进入日报、周报、月报的计费部分。

## 流量告警

告警使用当前计费周期的有效额度和对应统计方式。没有设置流量限额时不会发送百分比告警。达到阈值后，后续提醒按系统设定的增量触发，避免每次上报都重复通知。

## 主题兼容

公共接口保留原有字段，但额度字段映射为本周期有效额度。第三方主题不需要直接读取新增数据库字段，也不应自行把基础额度和追加额度再相加一次。
