# 流量与报告

流量页面、主题、仪表盘、报告和告警应使用一致的服务器设置，但它们展示的时间范围不同。

## 实际流量与额度

- **实际流量**：Agent 已经采集到的上传和下载。
- **基础额度**：服务器通常计费周期内的流量上限。
- **重置流量额度**：本周期因服务商重置、补偿等原因追加的额度。
- **本周期有效额度**：基础额度与本周期重置额度之和。

> **本周期有效额度** = 基础流量限额 + 本周期重置流量额度

重置流量额度不会修改 Agent 已经发生的流量，也不会伪造历史记录。进入下一个计费周期后，本周期追加额度自动清零。

## 统计方式

统计方式由服务器的流量设置统一决定。重置额度沿用同一个统计方式，不再维护第二套上传、下载或合计规则。

修改统计方式后，主题、进度条和流量告警会按新口径计算，但过去已经发出的报告不会被自动改写。

`2.2.1` 起，新节点第一次在“编辑信息”里设置该项时默认选择“总和”。这个默认值只用于尚未保存统计方式的新节点，不会迁移或覆盖已有节点的上传、下载、较大值或总和设置。

## 流量校准

::: info 2.1.12 正式版功能
流量校准已纳入 2.1.12，用于修正当前计费周期的已用流量。它与“重置流量额度”不是同一个功能。
:::

- **重置流量额度**：增加本周期可以使用的流量上限。
- **流量校准**：把本周期已经使用的上传、下载修正为服务商后台显示的实际数值。

例如，Agent 统计本周期已使用 `120 GB`，服务商后台显示 `100 GB`，可以将生效用量校准为 `100 GB`。系统会保留原始用量，并记录 `-20 GB` 的校准调整，而不是改写 Agent 原始计数。

校准窗口会显示：

- 当前计费周期。
- 原始上传与下载。
- 已应用的校准调整。
- 最终生效的上传与下载。
- 最近的校准记录。

同一周期可以多次校准。每次保存后，Agent 新上报的流量仍会继续累加；到下一个流量重置日，上一周期的校准不再影响新周期。计费周期按北京时间和服务器设置的重置日计算，设置为 31 日时，较短月份会自动使用当月最后一天。

校准值不能为负数。向下校准时，系统会按日期从后向前调整，并保证任何一天的用量都不会变成负数；如果现有历史数据不足以完成调整，保存会失败并在窗口中显示原因。

校准不会删除原始监测数据。仪表盘、流量告警、日报、周报、月报、公共接口和主题会统一使用校准后的生效用量，避免不同页面出现两套数字。

## 日报、周报和月报

报告从精确流量账本按北京时间日期汇总，并计入对应日期的流量校准调整：

- 日报：指定自然日。
- 周报：对应自然周范围。
- 月报：对应自然月范围。

“立即发送今日报告”还包含今天尚未结束的实时数据。由于后台写入和报告触发存在时间差，临界秒可能与页面刷新时看到的数字有极小时间差。

## 计费流量

只有设置了价格的服务器进入计费流量汇总。服务器没有价格或明确为免费时：

- 节点流量仍正常保存。
- 服务器详情仍显示上传和下载。
- 不进入仪表盘计费汇总。
- 不进入日报、周报、月报的计费部分。

这里的“计费流量”是按节点流量统计方式计算的用量，不等同于 2.3.0 账单中心的服务器租用成本。价格、周期、到期、附加费用和剩余价值见[账单中心](/admin/billing)。

## 流量告警

告警使用当前计费周期校准后的生效用量、有效额度和对应统计方式。没有设置流量限额时不会发送百分比告警。达到阈值后，后续提醒按系统设定的增量触发，避免每次上报都重复通知。

新服务器是否默认启用流量定时报告，以及负载静默、离线默认配置，见 [通知与告警](/admin/notifications)。

## 主题兼容

公共接口保留原有字段：额度字段映射为本周期有效额度，上传和下载字段映射为校准后的生效用量。第三方主题不需要读取新增数据库字段，也不应自行叠加重置额度或校准调整，否则会造成重复计算。
