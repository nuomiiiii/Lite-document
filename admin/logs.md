# 日志

“日志”页面用于查看 Lite 记录的系统运行、后台请求和错误事件。它与 Agent 本机日志不同；排查 Agent 服务启动、参数或网络连接时，仍应使用[Agent 安装与维护](/install/agent#查看日志)中的系统日志命令。

## 筛选与搜索

页面支持组合使用以下条件：

- **类型**：可同时选择多个日志类型，选项旁会显示对应记录数。
- **时间**：可同时选择多个日期。
- **搜索**：按 IP 或日志内容进行模糊搜索。

筛选和搜索由服务端对全部日志执行，不只检查当前页。当前条件会显示为筛选标签，可以单独移除或一次清空；结果数量和分页会随条件更新。

## 查看详情

列表显示日志 ID、IP、类型、内容和时间。较长内容会在表格中省略，悬停可快速查看；点击日志 ID 可以打开完整详情，包括 UUID 和未截断的内容。

日志时间会按浏览器所在时区显示。需要与服务器或代理日志对照时，应同时核对时区和具体时间，避免把同一事件误认为不同记录。

日志可用于确认操作和定位错误，但不能代替完整备份，也不应作为长期审计归档。需要长期保留的信息应由外部日志系统收集，或按实际运维流程另行归档。
