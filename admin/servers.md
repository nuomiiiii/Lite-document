# 服务器管理

服务器页负责节点身份、显示信息、流量口径、价格和远程入口。Agent 上报实时状态，后台保存管理设置。

## 添加服务器

创建服务器后会生成节点 UUID 和 Agent Token。Token 相当于节点凭据，不要公开到截图、日志或脚本仓库。

将面板地址和 Token 写入 Agent：

```bash
./Lite-agent --endpoint "https://example.com" --token "你的-token"
```

## 编辑服务器

常用设置包括：

- 名称、分组、排序和标签。
- 流量限额、统计方式和流量重置日。
- 价格、货币、到期时间和账单周期。
- 自定义国家/地区代码，用于 GeoIP 识别错误或广播 IP 场景。
- 远程管理权限与 Agent 配置。

国家/地区可输入两位代码，如 `HK`、`US`、`JP`。保存时会规范化代码，主题通过公共接口读取相同结果。

新节点第一次在“编辑信息”中设置流量统计方式时，默认选择“总和”，即按上传与下载之和计算用量。升级不会迁移或覆盖任何已有节点已经保存的统计方式。

## 新增服务器自动排序

“系统设置 → 通用 → 新增服务器自动排序”默认关闭。开启后，新服务器第一次上报并识别出国家/地区时，会按以下方式选择位置：

- 优先放到同一分组、同一国家/地区的最后一台服务器后面。
- 所有服务器都没有分组时，按国家/地区整理新节点。
- 没有可匹配的同组同国家/地区节点时，保留创建时的位置。

开关只影响之后加入的新服务器，不会重新排列已有服务器。需要完全自定义顺序时，保持关闭并继续使用手动排序。

## Agent 部署配置

每台服务器可以分别保存一套 Agent 部署配置。配置保存在 Lite 服务端，重新打开页面或更换管理员设备后仍会自动带出，适合重复生成重装指令。

以下运行配置支持“保存并下发”到在线 Agent：

- 采集间隔。
- 流量重置日。
- 包含或排除网卡。
- 包含挂载点。
- 内存缓存计入方式。
- GPU 监控。

流量重置日与服务器账单设置使用同一数值，修改任意一处后应保持一致。

以下七项只用于保存和生成安装或重装指令，不支持远程下发：

- 禁用远程控制。
- 忽略不安全证书。
- 禁用自动更新。
- 从网卡获取 IP 地址。
- GitHub 代理。
- 安装目录。
- 服务名。

这些选项涉及远程控制边界、TLS 校验、更新策略、地址来源或本机安装过程，修改后必须手动重新安装 Agent 才会生效。

### 下发状态

Agent 列只显示当前进度：

| 状态 | 含义 |
| --- | --- |
| 已保存 | 配置已存入 Lite，尚未得到本次在线应用确认 |
| 已发送 | 最新配置已发送给在线 Agent，正在等待确认 |
| 已生效 | Agent 已确认应用成功 |
| 应用失败 | Agent 返回失败；打开配置窗口查看原因后重试 |

同一离线节点的等待队列只保留最新配置。节点恢复连接后只会收到最后一次保存并下发的版本，不会依次应用已经过期的修订。

Agent 会向 Lite 上报当前生效配置，用于初始化尚未由面板管理的节点；已经保存的管理端配置不会被旧 Agent 状态反向覆盖。完整的配置上报、在线下发和结果确认建议使用 Lite-agent `2.3.0.0`。

Agent 进程运行但面板显示离线时，先确认 Lite 和 Lite-agent 均已更新到兼容版本。服务状态、日志和重启命令见 [Agent 安装与维护](/install/agent)。

负载通知规则也可设置“默认开启”。新加入的服务器会自动纳入已开启该选项的规则，现有服务器不受影响。离线通知、延迟监测告警和流量定时报告的默认配置见 [通知与告警](/admin/notifications)。

重新安装 Agent 本身不等同于一次“保存并下发”确认。如果列表仍显示“已保存”，需要对可下发配置执行一次“保存并下发”，由 Agent 返回确认后才会显示“已生效”。

## 操作按钮

服务器行中的操作通常包括：

- 轮换 Agent Token。
- 查看安装命令和 Agent 部署配置。
- 打开远程终端。
- 编辑服务器。
- 编辑账单与流量额度。
- 校准当前计费周期的流量。
- 删除服务器。

删除服务器会同时清理它的管理配置和关联历史数据。确认框会加粗显示目标服务器名称；提交前请再次核对，并确认没有主题、自动化或外部脚本仍依赖该节点。

## 账单与标签

服务器列表将账单和标签分列显示。账单保留横向价格与周期信息；标签使用带颜色的底框，与服务器详情和公开主题保持一致。价格、币种、周期、到期时间或附加费用需要调整时使用“编辑账单”，汇总与历史明细在[账单中心](/admin/billing)查看。

修改服务器资费会形成新的资费版本，不会按新价格回算已入账费用。流量重置和更换 IP 产生的费用作为附加账目进入账单中心。

## 流量校准

::: info 2.1.12 正式版功能
流量校准已纳入 2.1.12，用于修正服务商后台与 Agent 统计不一致的情况。
:::

服务器设置了流量重置日后，服务器行会显示“流量校准”按钮。打开后可以查看当前计费周期、原始用量、校准调整量和最终生效用量，并把上传、下载分别校准为服务商后台显示的实际数值。

输入支持 `10 GB`、`1.5 TB` 等常见格式。保存后仍可再次校准；最近的校准记录和失败原因会直接显示在窗口中。校准不会修改 Agent 原始计数，也不会删除监测历史，新产生的流量会继续在校准结果上累加。

如果还没有设置流量重置日，请先编辑服务器并完成设置。校准只在当前计费周期内生效，到下一个重置日会自动结束。

## 刷新与表单

服务器状态会定时刷新，但编辑弹窗中的输入值不会跟随列表刷新覆盖。长时间编辑时仍建议先保存再切换页面，避免浏览器刷新丢失尚未提交的内容。
