# 账单中心

账单中心用于统一查看服务器成本、到期时间、附加费用和剩余价值。入口位于后台左侧“账单中心”，包含“费用概览”“月度账单”和“年度账单”三个页签。

## 开始前配置服务器资费

账单中心读取服务器“编辑账单”中的价格、原始币种、计费周期和到期时间。服务器可处于以下状态：

| 状态 | 说明 |
| --- | --- |
| 周期付费 | 价格大于 0，且计费周期为有效天数 |
| 一次性 | 计费周期为 `-1`，费用在资费生效时一次入账 |
| 免费 | 明确设置为免费，不计基础费用 |
| 未配置 | 资费信息不完整，不进入正常基础费用计算 |

月付、季付、半年付和年付会按相应日历周期显示；其他正数按实际天数显示。修改价格、币种、周期或到期时间后，Lite 会保存新的资费版本，已经形成的历史账目不会按新价格重算。

Lite 会识别已经保存的货币代码和常见符号，包括 `¥`、`$`、`€`、`£` 和 `C$`。编辑后仍会保存规范化币种，但不会为了显示统一而改写历史流水中的原币金额。

## 费用概览

概览提供：

- 今日、本月和本年费用。
- 本月基础费用、附加费用和其他费用构成。
- 今年费用趋势。
- 所有有效资费的估算剩余价值，以及 30 天内到期数量。
- 每台服务器的原始资费、折算均费、本月累计、到期时间和剩余价值。

汇总和服务器列表只计算当前仍存在的服务器。删除服务器后，其节点不会继续出现在当前费用、到期数量或剩余价值中；已有账目和冲销记录仍保留在历史账期，便于审计。

服务器资费支持按国家/地区、分组、原始币种和到期范围筛选，也可搜索服务器名称、分组和标签。筛选项支持多选；清空筛选后恢复完整列表。

## 月度与年度账单

“月度账单”按月份汇总基础费用、流量重置、更换 IP、一次性费用和合计，并显示月均费用；“年度账单”按年份汇总相同分类，并提供同比信息。点击账期可查看费用明细。

基础费用按北京时间和服务器资费周期计算。系统每天完成上一日的费用入账；当前账期可能同时包含已结算和预计数据，界面会明确显示“进行中”“已结算”“预计”或“无记录”。

## 附加费用

当前可手工录入的附加费用包括：

- **流量重置**：在服务器流量/账单操作中录入重置流量费用。
- **更换 IP**：在服务器账单操作中录入更换 IP 费用。
- **一次性费用**：在服务器详情的“计费”页签中录入安装、升级、补差价等不会周期性重复的费用。

流量重置和更换 IP 使用服务器当前币种；一次性费用可选择币种并填写可选备注。三者都按点击确认时的北京时间进入对应账期，并可在账期明细中查看或作废。流量重置费用与重置流量额度是两个字段：前者进入账单，后者只改变本周期可用流量额度。

::: info 两种“一次性”不是同一项设置
服务器资费的计费周期设为 `-1` 时，表示整个服务器套餐是“一次性资费”，会在资费生效时自动进入基础费用。“一次性费用”按钮则是人工追加一笔独立费用，会显示在月度、年度账单的“一次性费用”列中。
:::

## 多币种与参考汇率

服务器始终保留原始币种和原币金额。账单中心目前可在 `CNY` 与 `USD` 间切换汇总币种，折算使用资费或费用形成时保存的参考汇率快照，因此之后汇率变化不会改写历史折算金额。

从旧版升级时，Lite 会为此前缺少参考汇率的资费补上升级时可用的汇率；已经保存过的历史汇率不会被覆盖。这样月均、年均和历史账目不会随着后续汇率刷新反复变化。

界面会显示汇率状态：最新、缓存、已过期或暂不可用。汇率暂不可用时，原币金额仍完整保存；等待汇率折算的记录会单独提示，不应手工修改原始金额来规避提示。

## 作废与冲销

账目不直接删除。对可作废的附加费用执行“作废”并填写原因后：

1. 原流水完整保留。
2. Lite 在原账期新增一笔等额冲销记录。
3. 月度、年度和明细合计同时反映冲销结果。

这种方式保留了操作人、时间、原始记录和原因，便于核对。基础费用和系统生成的预计项不会提供不适用的作废操作。

## 已有资费检查

导入或迁移已有服务器后，Lite 会根据价格、货币、周期和到期时间建立资费信息，不会把没有价格的服务器自动设为付费。建议逐台检查：

- 原始币种是否为受支持且拼写正确的币种代码。
- 计费周期和到期时间是否符合真实套餐。
- 一次性、免费和未配置服务器的状态是否正确。
- CNY/USD 汇总、剩余价值与 30 天内到期数量是否符合预期。

流量用量、额度和报告口径见[流量与报告](/admin/traffic)，服务器资费编辑见[服务器管理](/admin/servers)。
