# 用户与套餐 <PlusBadge />

本页仅适用于 Lite-Plus。节点用户是管理员分配的代理连接身份，不是面板管理员账号；套餐用于给这些用户设置额度、限速和期限。

## 节点用户

进入“节点管理 → 用户”，点击“新建”。先创建入站，再在用户表单中勾选至少一个入站；可以跨节点授权多个入站。

| 字段 | 说明 |
| --- | --- |
| 用户名 | 区分节点用户的名称 |
| 备注 | 可选显示说明 |
| 入站 | 该用户允许连接的入口，订阅只包含授权且可以分享的入站 |
| 套餐 | 可选择已有模板，也可不分配套餐 |
| 到期时间 | 留空表示不过期；按表单填写具体日期和时间 |
| 流量重置日期 | `0` 关闭，`1–31` 表示每月重置日 |
| 限速 | 单位 Mbit/s；`0` 不限速。有套餐时使用套餐限速 |
| 在线 IP | 同一节点上同时在线的来源 IP 上限，`0` 不限制；不是设备数量 |
| Flow | 可覆盖入站的 VLESS Flow，需与协议、内核及安全组合匹配 |
| 启用 | 关闭后停用用户，节点应用后结束相关连接 |
| 外部链接 | 将第三方分享链接或订阅合入该用户订阅，见[订阅与外部链接](/plus/subscriptions#外部链接与订阅) |

新用户会签发连接凭据，并自动生成一条订阅。需要查看完整连接参数时，点击“预览订阅”；首次显示的明文凭据请及时复制。

HTTP 入站也可在入站表单单独维护账号；这些账号与本页的节点用户分别管理。使用用户套餐、期限和订阅时，按节点用户分配入站，并以该用户的订阅凭据连接。

需要为特定用户或套餐设置客户端分流规则时，在[订阅模板](/plus/templates#指定套餐或用户)中选择“应用到…”，可分别为不同客户端指定模板。用户订阅的专属设置优先于有效套餐，再依次使用系统默认或基础配置。

## 额度、限速与重置

- **流量额度**：同一节点用户在已授权节点之间共用额度和已用量，由 Agent 上报后在主控汇总。它与“服务器”页面的整机流量额度分开计算。
- **限速**：按每个节点上该用户的双内核合计流量限制，不表示跨全部节点共用一个实时带宽上限。
- **在线 IP**：按节点限制同时连接的来源 IP。同一个出口 IP 下的多台设备不能据此区分成多个设备；不同节点的 IP 上限也分别执行。
- **每月重置**：按北京时间所选日期的 `00:00:00` 清零已用流量，额度不变。较短月份没有所选日期时按当月最后一天计算。

节点离线时，主控的新设置需要等节点重新连接后下发；节点已经应用的配置会保存在本地。确认修改是否到达节点，应查看下发状态。

## 套餐

进入“节点管理 → 套餐”，新建名称、流量额度、天数、限速与在线 IP 上限，然后在用户表单中选择套餐。

| 项目 | 说明 |
| --- | --- |
| 流量 | 表单以 GB 显示，内部按字节保存；输入 `1` 按 `1024³` 字节换算 |
| 天数 | 分配或续费的时长，每天按 24 小时计算 |
| 限速 | Mbit/s，`0` 不限速 |
| 在线 IP | 单节点并发来源 IP 上限，`0` 不限制 |

套餐修改会同步到当前使用该套餐的用户，更新额度、限速与在线 IP 上限；天数变化会按新旧天数差调整现有到期时间。修改套餐不会清零这些用户的已用流量，也不会解除人工停用。保存前应核对受影响用户。

用户不再分配套餐时，套餐关联会移除，套餐额度被清为 `0`；这表示没有额度上限，已用流量仍保留。需要继续限制时，重新分配套餐或通过对应接口设置额度。

## 续费、停用与删除

| 操作 | 效果 |
| --- | --- |
| 续费 | 需要已有套餐；未到期时从原到期时间延长，已到期时从当前时间起算 |
| 续费对流量的影响 | 只延长时间，不追加额度、不清零已用量，也不解除人工停用 |
| 停用 | 下发停用状态，节点应用后拒绝新连接并结束该用户已有连接 |
| 启用 | 恢复启用状态，仍受实际到期时间和剩余额度限制 |
| 删除 | 删除用户及关联入站授权、凭据、套餐分配、订阅和外部链接，并同步相关节点 |

这些“套餐”和“续费”用于记录与执行代理使用权限，不会向服务商付款，也不提供支付或普通用户购买入口。

## 在线状态与 IP 日志

用户列表显示在线状态、在线 IP、已用流量和期限。点击在线状态或 IP 可打开“IP 日志”，查看当前记录并刷新；“全部清除”清理记录，不等同于停用用户或强制断开连接。

入站授权等较长内容会折叠显示，可展开查看完整项目。电脑端可拖动表头调整列宽，或点击“重置列宽”恢复；设置仅保存在当前浏览器中，见[列表显示与列宽](/plus/#列表显示与列宽)。

在线状态依赖近期 Agent 上报，不是长期访问历史。需要查管理员做过哪些修改，可进入“节点管理 → 审计”。
