# 订阅模板 <PlusBadge />

本页仅适用于 Lite-Plus。入口为“节点管理 → 订阅 → 模板管理”。模板用于给客户端订阅提供 DNS、代理分组和分流规则；用户更新订阅时，主控将该用户有权使用的节点写入模板，生成对应客户端的完整配置。

使用此功能需配套更新 Plus 服务端与管理后台。模板在主控生成，已有节点无需为模板功能单独更新 Agent。

## 创建与导入

1. 点击“新建模板”，选择模板类型。
2. 选择“从基础模板开始”“导入文件”或“粘贴已有配置”。基础模板会填入该格式的最简配置，导入文件会根据扩展名识别类型。
3. 填写模板名称，编辑配置中的 DNS、分组和规则。
4. 选择“用于预览的订阅”和客户端，点击“生成预览”，核对实际生成内容。
5. 点击“保存模板”，再设置系统默认或应用到指定套餐、用户。

列表也可直接“导入文件”，并按模板类型筛选或搜索名称。导入文件与模板内容最大为 `1 MiB`；已保存模板的类型固定，需要更换类型时新建一份模板。

| 模板类型 | 文件 | 对应客户端 |
| --- | --- | --- |
| Clash | `.yaml` / `.yml` | Mihomo / Clash Meta、Clash、Stash |
| Loon | `.lcf` | Loon |
| Surge | `.conf` | Surge iOS、Surge macOS |
| sing-box | `.json` | sing-box |

保存时会清除模板内原有的静态代理节点；获取订阅时，再写入该用户获授权且可用的节点。需要添加第三方节点时，在用户的[外部链接与订阅](/plus/subscriptions#外部链接与订阅)中配置。

## 设置默认与应用范围

### 系统默认

点击模板旁的星标，可将其设为**同类型客户端的系统默认**。例如，一份 Clash 模板可同时成为 Mihomo、Clash 和 Stash 的默认模板；确认弹窗会列出受影响的客户端。

再次点击星标可取消默认。已有套餐或用户专属设置仍按其优先级使用；没有其他指定模板时使用内置基础配置。

### 指定套餐或用户

1. 点击模板的“应用到…”。
2. 选择“指定套餐”或“指定用户”，再选择具体对象。
3. 勾选适用客户端，核对“当前使用的模板”和本次应用范围。
4. 点击“应用此模板”。

指定用户实际绑定该用户的订阅。相同套餐或用户可以为不同客户端指定不同模板；列表中的使用范围可点击打开，继续调整绑定。

选择顺序如下：

| 优先级 | 使用的模板 |
| --- | --- |
| 1 | 当前用户订阅为该客户端指定的模板 |
| 2 | 当前有效套餐为该客户端指定的模板；有多条有效套餐分配时，先查最新分配 |
| 3 | 该客户端的系统默认模板 |
| 4 | 对应类型的内置基础配置 |

需要取消套餐或用户的专属设置时，在“应用到…”中选择对应对象和客户端，点击“恢复跟随默认”。这会移除所选客户端的专属绑定，按上表继续查找。

## 让客户端使用模板

模板适用于客户端自动识别或指定 `target` 的完整配置请求。在订阅编辑页开启“自动识别客户端”，或从“预览订阅”的客户端选择器复制专用地址，例如 `?target=mihomo`。

原有固定 `clash`、`sing-box` 格式及 `?format=` 请求保持原有节点列表输出；`v2ray` 使用 Base64 分享链接，不绑定规则模板。参数及选择顺序见[为指定客户端生成配置](/plus/subscriptions#为指定客户端生成配置)。

模板内容或绑定修改后，在客户端**下次更新订阅**时生效。已经导入客户端的旧配置需要主动更新订阅。

## 各类模板的填写方式

<div class="plus-settings-table">

| 类型 | 填写方式 |
| --- | --- |
| Clash / Mihomo | 使用完整 YAML 配置，支持妙妙屋 V3 的 `include-all`、`filter`、`exclude-filter` 和地区分组；DNS、路由及 `rule-providers` 配置会保留 |
| Loon / Surge | 保留 `[Proxy]`、`[Proxy Group]`、`[Rule]` 结构；在原生代理分组中用 `__PROXY_NODES__` 代表当前用户兼容的节点，也可使用原生正则选择 |
| sing-box | 使用包含 `outbounds` 数组的完整 JSON；在 `selector` / `urltest` 分组的 `outbounds` 中填写 `"{all}"` 或 `"__PROXY_NODES__"`，生成时替换为用户可用节点标签 |

</div>

导入 Loon / Surge 配置后，原 `[Proxy]` 节点内容会移除，Loon 的代理链按生成结果补入。sing-box 会保留选择、测速、直连等配置，并移除模板中的静态代理出站；没有可用节点的分组使用直连出站。

模板中引用节点时，使用自动收录、筛选条件或上述标记，避免继续引用导入时已清除的样例节点名称。共享模板不接受非空的 `proxy-providers` 或 `[Remote Proxy]` 远程节点订阅，外部节点应放在对应用户的附加链接中。

## 预览、导出与删除

“预览”会对照模板内容和所选用户订阅生成的最终配置，也可在编辑过程中先生成预览再保存。选择的用户及订阅必须有效，节点范围仍按该用户的授权计算。

生成器会按所选客户端筛选兼容节点；不支持的节点会在预览中提示并跳过。模板结构通过检查后，仍需使用实际客户端验证所选协议、传输和规则是否受支持。

编辑窗口支持“导出模板”和“另存为副本”；预览窗口支持“下载生成的配置”。导出模板用于复用规则，生成的配置用于该用户的实际客户端接入。

删除前，先取消星标默认，并在各使用范围中恢复跟随默认。仍有绑定的模板不能删除。

## 常见提示与处理

| 提示 | 处理 |
| --- | --- |
| 模板解析失败或结构无效 | 检查所选类型与文件格式是否一致，修正 YAML 缩进、JSON 语法或对应配置段后重新预览 |
| 引用了不存在的节点、分组或出站 | 检查规则和分组引用，节点列表使用自动收录、筛选条件或节点标记 |
| 客户端不支持某个节点 | 根据提示核对协议、传输和安全设置，改用兼容客户端或调整入站配置 |
| 外部节点无法解析 | 检查用户的外部分享链接或订阅内容是否有效，以及所选客户端是否支持该协议 |
| 模板仍被使用，无法删除 | 取消系统默认，并解除套餐和用户订阅的模板绑定后再删除 |
