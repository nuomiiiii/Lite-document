# MCP 代理与 AI 授权

MCP 代理让支持 MCP 的 AI 客户端临时管理你选定的服务器。入口位于后台“远程管理 → MCP 代理”，包含“接入设置”“授权详情”和“操作记录”三个页签。本页适用于 Lite `2.3.3`、Lite-agent `2.3.3.0`。

## 使用条件

1. 在“系统设置 → 通用”中开启“允许远程管理”和“启用 MCP 代理”。
2. 将目标节点升级到 Lite-agent `2.3.3.0`，并确认节点在线。
3. 在节点本地通过 `--enable-remote-control` 开启远程控制。MCP 与终端、文件和远程执行共用这个 Agent 开关，不需要另外安装 Agent 插件。
4. 使用能够连接远程 MCP 服务并完成浏览器授权的客户端；客户端和授权浏览器均能访问你的 Lite 地址。

MCP 代理默认关闭。节点仅能正常上报监控数据，不代表已经支持 MCP；显示“当前 Agent 不支持 MCP 完整管理，请升级”时，需要更新 Agent 并等待重新连接。

## 连接客户端

1. 打开“远程管理 → MCP 代理 → 接入设置”，复制“MCP 代理服务地址”，例如 `https://monitor.example.com/mcp`。
2. 在 AI 客户端添加远程 MCP 服务，填入复制的地址并发起连接。支持浏览器授权的客户端会打开 Lite 授权页面；其他客户端需要使用兼容的本地适配器，具体字段以客户端说明为准。
3. 在浏览器登录 Lite，核对请求连接的客户端名称与回调地址。
4. 选择允许管理的服务器，设置授权时长，按需填写用途备注。
5. 账号已启用 2FA 时输入两步验证码，否则输入管理员密码，再点击“授权并连接”。密码和验证码只提交给 Lite。
6. 页面显示“授权完成”后，回到 AI 客户端继续操作。

授权绑定发起请求的客户端。点击“新建授权”后若提示没有客户端连接请求，应先完成客户端添加服务的步骤；此页面不提供通用 Token。服务器详情中的“授权 AI”可以预选当前节点，同样需要先有客户端连接请求。

## 授权范围与时长

当前提供“完整管理模式”：在有效期内，AI 可以在所选服务器上执行命令、使用交互终端、上传下载及读写文件，Lite 不会逐次弹窗确认。操作权限等同于 Agent 的运行账户；授权到期不会撤销已经完成的文件修改或命令效果。

“接入设置”可调整以下默认值，修改后点击“保存设置”：

| 设置 | 默认值 | 可选范围 |
| --- | --- | --- |
| 默认授权时长 | 30 分钟 | 1 分钟至站点设置的最长时长 |
| 最长授权时长 | 24 小时 | 1 分钟至 24 小时 |
| 每次授权最大并发 | 4 个操作 | 1–16 个操作 |

授权时长从点击确认开始计算，可以使用整数分钟或小时。默认时长不能超过最长时长；例如 90 分钟应使用分钟单位填写。

MCP 授权只允许访问所选节点及其操作，不授予 Lite 管理员账号权限。API Key、Agent 安装凭据和浏览器终端的短期授权不能替代 MCP 授权。

## 查看记录与撤销

- **授权详情**：按客户端或服务器搜索，查看所选节点、剩余时间、运行状态和并发使用情况；打开详情可核对授权人、用途和到期时间。
- **操作记录**：查看 AI 发起的命令、终端和文件操作及其结果，支持筛选、搜索和“导出记录”；导出格式为 CSV。
- **撤销**：停止接受该授权的新操作，并通知 Agent 结束关联任务与连接。“撤销全部”用于结束当前全部有效授权。
- **重新授权**：到期或撤销后，需要重新完成客户端连接与管理员验证。重新开启站点开关不会恢复已经撤销的授权。

授权和操作记录默认保留最近 7 天，需要长期留存时请及时导出。撤销或到期会结束相关访问，但已经完成的操作不会自动回滚。

退出授权时使用的 Lite 登录会话、删除该会话、修改密码或相关账号安全状态，会使关联 MCP 授权失效。Lite 服务重启后也需要重新授权。关闭“启用 MCP 代理”会撤销 MCP 授权；关闭“允许远程管理”还会停止其他远程管理能力。单纯关闭授权提示或浏览器页面不等于撤销授权。

## 接入问题

| 现象 | 处理方式 |
| --- | --- |
| MCP 页面无法进入或服务地址返回 404 | 检查 Lite 版本，以及“允许远程管理”“启用 MCP 代理”两个开关 |
| 授权页没有待连接客户端 | 先在 AI 客户端添加 MCP 服务地址并发起连接，再刷新授权请求 |
| 节点无法选择 | 检查在线状态、Agent 版本和本地远程控制开关 |
| 验证码被拒绝 | 同一个验证码不能重复使用，刚完成登录时请等待下一组验证码 |
| 客户端连接后反复要求登录 | 检查授权是否到期、被撤销，或授权所绑定的 Lite 登录会话是否已失效 |
| 页面可访问，客户端连接却被拦截 | 检查代理是否转发 MCP 和 OAuth 路径，以及 Cloudflare Access 是否允许客户端访问 |

MCP 使用面板下的 `/mcp`、`/oauth/*` 和 `/.well-known/*` 路径。反向代理及 Cloudflare Access 的配置见[反向代理与 Tunnel](/security/reverse-proxy#cloudflare-access)。
