# 远程终端与文件

远程终端、文件管理和远程执行只适用于你拥有或已经获得授权管理的设备。Agent 通常以高权限账户运行，启用前应确认管理员账号和面板访问范围可信。

## 使用条件

- 在 Lite“系统设置 → 通用”中开启“允许远程管理”。
- Agent 在线，并在节点本地使用 `--enable-remote-control` 开启远程控制。
- 使用支持当前远程协议的 Lite-agent `2.3.1.0`。
- 管理员已经登录，并在进入远程页面时完成重新验证。
- 反向代理支持 WebSocket。

站点开关与 Agent 本地开关必须同时开启。新安装的 Lite 和 Lite-agent 默认关闭远程管理；已有实例升级会保留原有状态。Lite 与 Agent 安装在同一台服务器时，该节点按普通服务器处理，不需要额外放行参数。

Docker Agent 重建时如果未保留远程控制配置或状态，也未显式指定开关，会默认关闭远程控制。需要使用时，请在容器参数中明确传入 `--enable-remote-control`。

Lite 不强制面板使用 HTTPS，但 HTTP/WS 无法保护链路中的密码、验证码、命令和文件内容。选择明文部署时，应自行评估网络环境和风险。

## 重新验证

进入远程终端或提交远程执行前，需要进行一次页面专属验证：

- 账号已启用 2FA 时，输入当前 TOTP 验证码。
- 账号未启用 2FA 时，重新输入当前管理员密码。
- 仅通过 SSO 登录、未启用 2FA 且没有本地密码的账号，暂时不能使用远程管理；已启用 2FA 时可以使用当前 TOTP 验证码完成验证。

验证结果只在当前页面内短时有效，最长 10 分钟。一次验证可以在当前远程终端工作区中打开多个节点会话；过期后再创建会话需要重新验证。关闭页面、退出登录、删除登录会话、修改密码或账号安全状态后，授权会失效，已有远程连接也会被关闭。

远程执行与终端使用相同的安全边界，但授权互不混用。仅有管理员 Cookie 或 API Key 不能跳过页面重新验证。

## 多会话与节点

从服务器列表或远程终端节点列表进入时，终端会在独立页面打开。一个登录会话最多同时保留 16 个待连接或已连接的远程会话，整个 Lite 实例最多 64 个；达到限制时，关闭不再使用的终端后重试。

单个远程连接最长持续 2 小时，到时需重新连接；创建新连接时如果页面验证已经过期，还需重新验证。这个连接时限与前述 10 分钟的验证有效期不同。

服务器离线、Agent 未开启远程控制或版本不支持当前协议时，页面会显示对应原因。旧终端协议已经移除，不会自动降级；看到 Agent 版本过旧提示时应升级节点。

## 文件管理

文件管理支持上传、下载、目录操作、分页列表和批量选择。先用左键进入目录或完成选择，再使用右键菜单对已选文件执行操作。

上传、下载和文件操作有会话级并发限制，关闭会话后未完成的任务会被取消并清理。大文件下载还受浏览器和反向代理超时影响；出现中断时应同时检查代理读取超时、缓冲和连接限制。

## WebSocket 403

常见原因：

1. 站点或 Agent 本地没有开启远程管理。
2. 登录会话或页面验证已经过期。
3. Cloudflare 或反向代理没有转发 `Upgrade` 和 `Connection`。
4. 浏览器访问地址的来源不被当前面板接受。
5. Cloudflare Access 允许页面访问但拦截 WebSocket。

先确认两个远程开关、Agent 版本和登录状态，再检查反向代理及后端日志中的实际状态码。
