# 远程终端与文件

远程终端、文件管理和远程执行只适用于你拥有或已经获得授权管理的设备。Agent 通常以高权限账户运行，启用前应确认管理员账号和面板访问范围可信。

## 使用条件

- 在 Lite“系统设置 → 通用”中开启“允许远程管理”。
- Agent 在线，并在节点本地使用 `--enable-remote-control` 开启远程控制。
- 使用配套 Lite-agent `2.3.3.0`。
- 管理员已经登录，并在进入远程页面时完成重新验证。
- 反向代理支持 WebSocket。

站点开关与 Agent 本地开关必须同时开启。新安装的 Lite 和 Lite-agent 默认关闭远程管理；已有实例升级会保留原有状态。Lite 与 Agent 安装在同一台服务器时，该节点按普通服务器处理，不需要额外放行参数。

Docker Agent 重建时如果未保留远程控制配置或状态，也未显式指定开关，会默认关闭远程控制。需要使用时，请在容器参数中明确传入 `--enable-remote-control`。

Lite 不强制面板使用 HTTPS，但 HTTP/WS 无法保护链路中的密码、验证码、命令和文件内容。选择明文部署时，应自行评估网络环境和风险。

## 重新验证

进入远程终端或提交远程执行前，需要进行一次重新验证：

- 账号已启用 2FA 时，输入当前 TOTP 验证码。
- 账号未启用 2FA 时，重新输入当前管理员密码。
- 仅通过 SSO 登录、未启用 2FA 且没有本地密码的账号，暂时不能使用远程管理；已启用 2FA 时可以使用当前 TOTP 验证码完成验证。

同一次页面加载中切换后台路由可以继续使用对应范围的有效授权；刷新或关闭页面后，浏览器会丢失授权，需要重新验证。退出登录、删除当前登录会话、修改密码或账号安全状态后，服务端授权会失效，已有远程连接也会被关闭。

关闭站点“允许远程管理”会撤销远程授权、关闭现有会话并清理待处理的远程任务。已打开的其他后台页面会通过设置同步和轮询更新状态。

远程执行与终端使用相同的安全边界，但授权互不混用。

## 多会话与节点

从服务器列表或服务器详情打开终端后，远程管理页面会保留后台导航。点击“打开服务器”选择节点，即可在当前窗口添加会话页签；同一台服务器可以重复打开，每个会话独立运行。页签支持拖动排序、切换和单独关闭。

浏览器标签标题显示当前节点名称，有已连接会话时还会显示连接数量。此时刷新或关闭页面会请求浏览器确认离开，离开后现有会话断开；提示是否显示及其形式以浏览器为准。

页面最多同时打开 16 个远程页签。一个登录会话最多同时保留 16 个待连接或已连接的远程会话，整个 Lite 实例最多 64 个；达到限制时，关闭不再使用的终端后重试。

单个远程连接最长持续 2 小时，到时需重新连接；创建新连接时如果短期授权已经过期，还需重新验证。

服务器离线、Agent 未开启远程控制或版本不支持当前协议时，页面会显示对应原因。旧终端协议已经移除，不会自动降级；看到 Agent 版本过旧提示时应升级节点。

## 文件管理

电脑端进入终端时默认收起侧栏，点击“打开侧栏”后可在“文件”和“命令”间切换；手机端可使用底部的“终端”“文件”“命令”切换视图。

文件管理支持上传、下载、目录操作、分页列表和批量选择。先用左键进入目录或完成选择，再使用右键菜单对已选文件执行操作。

上传、下载和文件操作有会话级并发限制，关闭会话后未完成的任务会被取消并清理。大文件下载还受浏览器和反向代理超时影响；出现中断时应同时检查代理读取超时、缓冲和连接限制。

根目录下拉框会同时保留用户主目录与 Agent 返回的文件系统根目录；Windows 节点会列出可用盘符。进入子目录后可继续通过路径栏或上级按钮导航。

“命令”中提供命令剪贴板，可保存和维护常用命令。终端外观设置位于“远程管理 → 终端设置”；需要批量下发命令时使用“远程管理 → 远程执行”。

## MCP 与 AI 管理

需要 AI 客户端管理服务器时，使用“远程管理 → MCP 代理”。它需要额外开启站点 MCP 开关，并为客户端选择节点、设置有效期和完成验证；浏览器终端授权不能直接用于 MCP。完整步骤见[MCP 代理与 AI 授权](/remote/mcp)。

## WebSocket 403

常见原因：

1. 站点或 Agent 本地没有开启远程管理。
2. 登录会话或远程授权已经过期。
3. Cloudflare 或反向代理没有转发 `Upgrade` 和 `Connection`。
4. 浏览器访问地址的来源不被当前面板接受。
5. Cloudflare Access 允许页面访问但拦截 WebSocket。

先确认两个远程开关、Agent 版本和登录状态，再检查反向代理及后端日志中的实际状态码。
