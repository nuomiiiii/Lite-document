# 主题管理

主题管理用于导入、启用、更新、配置和移除公开大屏主题。主题列表、主题市场和全部管理操作都要求管理员登录会话，API Key 不能查看或修改。

主题只影响公开大屏，不会替换管理后台、首次安装、远程终端、文件管理或错误页面。

## 导入与启用

1. 打开“外观与主题 → 主题管理”。
2. 导入主题压缩包或按主题说明安装。
3. 在已安装主题中选择并启用。
4. 回到公共首页确认实际主题已经切换。

全新安装默认提供 [Lite-Theme](https://github.com/nuomiiiii/Lite-theme)。它与其他主题一样支持更新和删除，但只有在系统中还存在另一个可用主题时才能删除。主题管理始终要求至少保留一个可用主题，避免公开大屏没有渲染入口。

当前配套 Lite-Theme 为 `1.2.9`，公开大屏与后台采用统一的 UI 风格，重新调整首页卡片、节点详情和图表布局。资源使用与历史趋势支持显示 Swap，探测延迟保留两位小数；整段探测失败时曲线显示断点，部分失败时仍显示成功样本的延迟及实际丢包率。

“显示剩余价值”默认开启，节点卡片会在“剩余 X 天”旁边显示剩余价值。管理员登录后，公开大屏右上角显示管理员头像，点击可进入后台；退出后恢复为登录按钮。

私有站点未登录时会先显示访问提示，不会提前加载实时数据；登录失效后也会返回提示页，不再反复重连。节点账单周期会根据到期日和计费周期计算起始日，首页实时上下行速率使用十进制单位。此前已有的负载状态颜色、卡片带宽开关、探测曲线跳转、列表位置恢复和手机端紧凑布局继续保留。

原经典主题不再捆绑在 Lite 中。如需使用，可单独安装 [lite-Classic](https://github.com/nuomiiiii/lite-Classic)；它是独立提取版本，不代表后续一定持续维护。

导入成功但首页仍是默认主题时，检查：

- 主题是否只是安装而没有启用。
- 浏览器或 Cloudflare 是否缓存旧首页和 Service Worker。
- 主题清单是否声明了正确入口文件。
- 主题文件是否与当前 Lite 版本兼容。
- 主题包根目录是否包含优先使用的 `Lite-theme.json`，或用于旧主题兼容的 `komari-theme.json`。

## 主题包大小与网络安装

主题 ZIP 最大为 128 MiB。直接上传、更新已安装主题、从 GitHub 安装和从主题市场安装都使用相同限制。

通过网络安装或更新时，下载地址只能使用 HTTP 或 HTTPS，并且必须解析到可公开访问的地址；跳转后的地址也会重新检查。地址指向本机、局域网、保留网段，或下载过程中超过大小限制时，后台会拒绝安装。遇到这类错误时，应确认主题仓库和安装包使用公开直链，不要关闭地址检查。

## GitHub 代理

如果服务器访问 GitHub 不稳定，可在“系统设置 → 通用 → GitHub 代理”填写代理地址，例如 `https://gh-proxy.com`；留空表示不使用代理。该地址用于主题 Release 查询、主题 GitHub 安装、主题市场 GitHub 资源下载，以及主题一键更新和自动更新中的 GitHub 来源。保存时只接受 HTTP 或 HTTPS 外部地址，并会去除查询参数、片段和末尾斜杠。

在节点部署指令中勾选 GitHub 代理时，后台会自动填入当前设置的地址；部署命令仍可按需修改。

## 更新主题

### 一键更新

1. 打开“外观与主题 → 主题管理”，点击“一键更新”。
2. 确认更新已安装主题，等待页面显示结果。
3. 查看每个主题的状态，再打开公开大屏确认显示正常。

一键更新会检查所有已安装主题，不只检查当前启用的主题。来源为 GitHub 仓库时读取最新 Release；来源为主题包直链时下载并检查包内版本。没有来源地址的主题会跳过，可按主题作者说明手动上传新包。

| 结果 | 含义与后续操作 |
| --- | --- |
| 已更新 | 已安装来源提供的不同版本，检查公开大屏和主题设置 |
| 已是最新版本 | 来源版本与已安装版本相同，无需重新安装 |
| 已跳过 | 没有可用来源地址，需手动提供更新包 |
| 更新失败 | 查看该主题的错误，检查来源、网络、包大小和主题标识后重试 |

一个主题更新失败不会阻止其他主题继续检查。已有批量更新正在进行时，请等待本轮结果后再发起更新。

### 自动更新

点击“自动更新”，打开开关、设置间隔并保存。默认关闭，默认间隔为 **24 小时**；可填写 **1–720 的整数小时**，也可选择页面提供的常用间隔。

启用或修改间隔后，按新的间隔计算下次执行时间。后台会显示上次执行时间、下次执行时间和最近结果；Lite 服务端在后台执行，无需保持浏览器打开，正常重启后继续使用已保存的计划。自动更新与一键更新使用相同来源和检查规则。

主题更新后如仍看到旧页面，刷新浏览器并检查代理缓存。更新只影响公开大屏主题，服务端和 Agent 的更新方法见[更新与数据库迁移](/install/update)。

## 主题设置

主题的语言、布局和外观选项由主题自己提供；不同主题可用的设置项可能不同。只有主题提供了配置时，后台才会显示对应的设置入口。

### Lite-Theme 首页探测任务

1. 打开 Lite-Theme 的主题设置，进入“探测任务”页。
2. 为每台服务器选择已分配给它的延迟监测任务，每台最多 4 个。
3. 拖动已选任务调整显示顺序，然后保存主题设置。

未配置的节点沿用延迟监测任务的默认顺序；清空选择或恢复默认后，重新使用默认顺序。该配置只控制 Lite-Theme 首页卡片，不会修改监测任务本身或其他主题的顺序。

### 手机端概览

“内容设置”中的“手机端显示概览”默认关闭。开启后，手机端首页显示连接数、实时流量、累计流量、CPU、内存和硬盘六项概览。其余手机端紧凑布局、网络质量两列、丢包率开关和探测延迟默认时间继续保留。

需要制作或适配主题时，请直接查看[主题开发指南](/development/theme)，其中集中说明清单格式、配置类型、资源路径和公共接口。

## 仪表盘跳转

仪表盘排行会按当前主题支持的页面打开相应详情：

- 平均时延、延迟抖动和近 15 分钟丢包均按任务展示，进入条目对应的具体 Ping 任务。
- 其他服务器排行进入服务器详情。

旧主题没有提供对应页面时，会打开兼容的服务器详情地址。

## PWA 与站点信息

公开大屏安装到主屏幕时，会使用后台设置的站点名称、描述和网站图标。后台改名后如果主屏幕仍显示旧名称，卸载后重新安装即可。

## 带宽

管理员在服务器设置里填写带宽后，支持该功能的主题可以在节点卡片中显示。它表示线路带宽，不是当前实时网速；默认 Lite-Theme 可通过“显示带宽”开关控制。

## 国家/地区图标

服务器手动设置国家/地区代码后，主题会优先使用该值显示旗帜或地区名称。代码应填写为 `HK`、`US`、`JP` 这类两位大写格式。
