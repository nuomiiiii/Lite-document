# 主题管理

主题管理用于导入、启用、更新、配置和移除公开大屏主题。主题市场与已安装主题位于同一管理流程中，避免跳转后失去当前上下文。

主题只影响公开大屏，不会替换管理后台、首次安装、远程终端、文件管理或错误页面。

## 导入与启用

1. 打开“外观与主题 → 主题管理”。
2. 导入主题压缩包或按主题说明安装。
3. 在已安装主题中选择并启用。
4. 回到公共首页确认实际主题已经切换。

全新安装默认提供 [Lite-Theme](https://github.com/nuomiiiii/Lite-theme)。它与其他主题一样支持更新和删除，但只有在系统中还存在另一个可用主题时才能删除。主题管理始终要求至少保留一个可用主题，避免公开大屏没有渲染入口。

当前默认 Lite-Theme 为 `1.0.9`。私有站点未登录时会先显示访问提示，不会提前加载实时数据；登录失效后也会返回提示页，不再反复重连。节点账单周期会根据到期日和计费周期计算起始日，首页实时上下行速率使用十进制单位。此前已有的负载状态颜色、卡片带宽开关、探测曲线跳转、列表位置恢复和手机端紧凑布局继续保留。

原经典主题不再捆绑在 Lite 中。如需使用，可单独安装 [lite-Classic](https://github.com/nuomiiiii/lite-Classic)；它是独立提取版本，不代表后续一定持续维护。

导入成功但首页仍是默认主题时，检查：

- 主题是否只是安装而没有启用。
- 浏览器或 Cloudflare 是否缓存旧首页和 Service Worker。
- 主题清单是否声明了正确入口文件。
- 主题文件是否与当前 Lite 版本兼容。
- 主题包根目录是否包含优先使用的 `Lite-theme.json`，或用于旧主题兼容的 `komari-theme.json`。

## 主题包大小与网络安装

主题 ZIP 最大为 128 MiB。直接上传、更新已安装主题、从 GitHub 安装和从主题市场安装都使用相同限制。

通过网络安装或更新时，下载地址只能使用 HTTP 或 HTTPS，并且必须解析到可公开访问的地址；跳转后的地址也会重新检查。地址指向本机、局域网、保留网段，或下载过程中超过大小限制时，后台会拒绝安装。遇到这类错误时，应确认主题仓库和安装包使用公开直链，不要关闭地址检查。

## 主题设置

主题的语言、布局和外观选项由主题自己提供；不同主题可用的设置项可能不同。只有主题提供了配置时，后台才会显示对应的设置入口。

需要制作或适配主题时，请直接查看[主题开发指南](/development/theme)，其中集中说明清单格式、配置类型、资源路径和公共接口。

## 仪表盘跳转

仪表盘排行会按当前主题支持的页面打开相应详情：

- 平均时延和延迟抖动是多任务综合结果，进入服务器网络总览。
- 近 15 分钟丢包进入该服务器最差的具体 Ping 任务。
- 其他服务器排行进入服务器详情。

旧主题没有提供对应页面时，会打开兼容的服务器详情地址。

## PWA 与站点信息

公开大屏安装到主屏幕时，会使用后台设置的站点名称、描述和网站图标。后台改名后如果主屏幕仍显示旧名称，卸载后重新安装即可。

## 带宽

管理员在服务器设置里填写带宽后，支持该功能的主题可以在节点卡片中显示。它表示线路带宽，不是当前实时网速；默认 Lite-Theme 可通过“显示带宽”开关控制。

## 国家/地区图标

服务器手动设置国家/地区代码后，主题会优先使用该值显示旗帜或地区名称。代码应填写为 `HK`、`US`、`JP` 这类两位大写格式。
