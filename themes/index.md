# 主题管理

主题管理用于导入、启用、配置和移除第三方主题。主题市场与已安装主题位于同一管理流程中，避免跳转后失去当前上下文。

## 导入与启用

1. 打开“外观与主题 → 主题管理”。
2. 导入主题压缩包或按主题说明安装。
3. 在已安装主题中选择并启用。
4. 回到公共首页确认实际主题已经切换。

导入成功但首页仍是默认主题时，检查：

- 主题是否只是安装而没有启用。
- 浏览器或 Cloudflare 是否缓存旧首页和 Service Worker。
- 主题清单是否声明了正确入口文件。
- 主题文件是否与当前 Komari Lite 版本兼容。

## 主题设置

默认主题支持简体中文、繁体中文、英文、日文和印尼文。第三方主题必须自行提供翻译；后台语言切换不能自动翻译主题内部硬编码文本。

## 流量字段

公共接口会把兼容额度字段映射为本周期有效额度，包括本周期追加的重置流量额度。主题应直接使用接口结果，不要再读取内部设置或重复相加。

服务器实际上传、下载和当前周期用量也应从公共接口读取。主题不应直接访问 SQLite 文件或依赖 Agent 的私有存储。

## 国家/地区图标

服务器手动设置国家/地区代码后，公共接口优先返回该值，用于修正 GeoIP 错误和广播 IP 场景。主题应将两位代码标准化为大写后再映射旗帜或地区名称。
